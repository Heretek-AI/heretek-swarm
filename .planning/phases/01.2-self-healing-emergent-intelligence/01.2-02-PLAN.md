# Plan: Self-Maintenance System

**Requirements:** HEAL-03 (Self-Maintenance Without External Intervention)
**Wave:** 2
**Priority:** P1

---

## Context

HEAL-03 requires the system to self-maintain without external intervention. The research identified no existing self-maintenance infrastructure — this is net new work. Three sub-tasks:

1. **Log rotation** — automated cleanup of old logs
2. **Database maintenance** — vacuum, analyze, prune orphaned records
3. **Config drift detection** — snapshot baseline, compare on interval, alert on drift

**Key patterns from existing codebase:**
- `SwarmMetricsCollector._update_health_score()` in observability/metrics.py for health tracking
- `StateRepository` in state/repository.py for state operations
- Scheduled task patterns from `_monitor_loop` in steward.py
