Configure PostgreSQL connection pooling per DEPLOY-03:

1. **Add asyncpg connection pool** to repository.py:
   ```python
   from asyncpg import create_pool, Pool
   from typing import Optional
   
   class StateRepository:
       _pool: Optional[Pool] = None
       
       @classmethod
       async def initialize_pool(cls, min_size: int = 10, max_size: int = 100):
           """Initialize connection pool."""
           cls._pool = await create_pool(
               dsn=os.environ["DATABASE_URL"],
               min_size=min_size,
               max_size=max_size,
               command_timeout=60,
               max_queries=50000,
               max_inactive_connection_lifetime=300,
           )
       
       @classmethod
       async def close_pool(cls):
           """Close connection pool."""
           if cls._pool:
               await cls._pool.close()
       
       @classmethod
       async def get_connection(cls) -> Pool:
           """Get connection from pool."""
           if not cls._pool:
               await cls.initialize_pool()
           return cls._pool
   ```

2. **Update all repository methods** to use pool from `get_connection()` instead of creating new connections per request.

3. **Add pool metrics**:
   - Expose `pool.get_size()` and `pool.get_idle_size()` 
   - Log warning if utilization > 80%
   - Add to health endpoint

4. **Update docker-compose postgres** configuration:

