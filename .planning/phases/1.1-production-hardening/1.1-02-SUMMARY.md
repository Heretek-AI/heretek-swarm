### 3. DEPLOY-03: Database Connection Pooling (Modified)

**File Modified:** `src/heretek_swarm/state/repository.py`

**Changes:**
1. Added asyncpg import with `importlib.util.find_spec` pattern
2. Added pool configuration constants: `DEFAULT_MIN_SIZE=10`, `DEFAULT_MAX_SIZE=100`
3. Added class methods:
   - `create_pool()` - Creates asyncpg connection pool
   - `close_pool()` - Closes connection pool
   - `get_pool()` - Gets or creates pool singleton
   - `get_pool_stats()` - Returns pool utilization metrics
   - `initialize()` - Factory method for repository + pool creation

**Pool Configuration:**
```python
DEFAULT_MIN_SIZE = 10
DEFAULT_MAX_SIZE = 100
POOL_UTILIZATION_WARNING_THRESHOLD = 0.8  # 80%

_pool_config = (
    ("min_size", 10),
    ("max_size", 100),
    ("command_timeout", 60),
    ("max_queries", 50000),
    ("max_inactive_connection_lifetime", 300),
)
```
